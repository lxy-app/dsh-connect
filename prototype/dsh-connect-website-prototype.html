Secure by default

安全不是附加项，
而是每一次连接的默认值。

权限边界、会话事实源与审批语义从架构底层保持一致，让“远程可用”不以“放松控制”为代价。

01 / GRANT

默认拒绝

查看、发送、取消、审批分别授权；手机配对本身不会获得桌面访问权限。

02 / SOURCE

事实留在 DSH

DSH Session Log 是会话事实源。Server 不直接读取 DSH 内部文件，也不替代桌面执行 Agent。

03 / NETWORK

桌面主动出站

Connector 主动连接 Server，无需把 DSH 桌面端口暴露到公网。

04 / APPROVAL

审批失败关闭

只允许明确的一次性决定。超时、离线或协议异常不会被伪造成批准。
