# DSH Connect 高保真原型说明

- 原型文件：[../dsh-connect-prototype.html](../dsh-connect-prototype.html)
- 类型：独立、可交互 HTML
- 状态：用于产品评审与交互演示
- 数据：全部为模拟数据

## 1. 打开方式

在 macOS 上双击文件，或在文件管理器中选择默认浏览器打开。

不需要：

- 安装 DSH 插件。
- 启动 Go Server 或 Web Server。
- 安装 React、React Native 或 Node 依赖。
- 连接 DeepSeek Harness。
- 访问互联网。

原型可以离线运行，所有 HTML、CSS 和 JavaScript 均在同一个文件中。

## 2. 原型与真实产品的边界

### 原型包含

- 移动 App 高保真页面。
- 桌面 Connector 接入与授权流程。
- Web 管理后台页面。
- 前端状态切换和模拟反馈。
- 明暗主题与响应式布局。

### 原型不包含

- 真实 DSH Host API 调用。
- 真实 Go Server、认证、WSS 或数据库。
- 真实 React Native 工程。
- 真实会话、工具执行或审批。
- 真实二维码配对、推送或设备吊销。

原型中 `MacBook Pro`、`Liwei MacBook`、`Connector 1.0.0`、会话消息和审批记录均为演示内容。

## 3. 顶部三套视图

```text
移动 App｜桌面 Connector｜管理后台
```

这三套视图对应真实产品的三个不同使用端：

- App：移动控制。
- Connector：将已有 DSH 桌面绑定为受控设备。
- Admin：组织、设备和权限治理。

## 4. 推荐演示路径：完整接入 DSH 桌面

### 第一步：生成桌面配对码

进入：

```text
管理后台 → 设备管理 → 添加桌面
```

页面展示：

- 一次性配对码 `DC-8F2K-91PQ`。
- 示意二维码。
- Server 地址。
- 有效期。
- “生成配对码 → 桌面建立连接 → 授权并上线”步骤条。

### 第二步：打开桌面 Connector

点击“打开桌面 Connector”。

未连接页面展示：

- Server 地址。
- 配对码输入框。
- 主动 WSS 连接说明。
- Connector 与 DSH Host API、Go Server、App 的关系。

也可以直接通过顶部“桌面 Connector”进入，并点击“使用演示配对码”。

### 第三步：连接 Server

点击“连接 Server”。

原型进入待授权状态，模拟 Server 已完成配对码校验。

### 第四步：桌面确认授权

核对：

- Server。
- 桌面名称。
- 设备指纹 `8F:42:9C:71:DC`。
- 工作区选择。
- 远程执行风险提示。

点击“确认授权并上线”。

### 第五步：查看三端联动

- Connector 显示在线、心跳、工作区和接入记录。
- 点击“在管理后台查看”，后台显示接入成功。
- 后台设备列表新增 `Liwei MacBook`。
- 切换到移动 App → 设备，新增同一桌面。
- App 的“DSH 桌面如何接入？”卡片可重新进入流程。

## 5. 移动 App 页面与交互

### 5.1 会话

- 搜索会话。
- 全部、运行中、待处理、已完成筛选。
- 点击会话卡片进入聊天。
- 新建会话。

### 5.2 会话详情

- 查看用户、Assistant 和工具调用卡片。
- 输入补充指令并发送。
- 模拟 DSH 接受指令和 Assistant 回复。
- 返回会话列表。

### 5.3 待办与审批

- 打开“运行集成测试”审批。
- 查看命令、工作区、设备、发起者和有效期。
- 拒绝后返回待办。
- 允许一次需要经过 Face ID 模拟确认。
- 处理后待办状态清空。

### 5.4 设备

- 查看桌面在线状态。
- 查看手机受信任状态。
- 打开 DSH 接入说明。
- 新增桌面在授权完成后出现。

### 5.5 我的

- 任务通知、审批通知、生物识别和锁屏隐私开关。
- Server、设备密钥和诊断入口。
- 明暗主题由顶部主题按钮控制。

## 6. 管理后台页面与交互

| 页面 | 演示内容 |
|---|---|
| 概览 | 指标、近 7 日趋势、实时会话、审批和最近动态 |
| 用户与角色 | 用户列表、角色、设备和授权入口 |
| 设备管理 | 桌面列表、添加桌面向导、配对状态、吊销入口 |
| 访问策略 | 桌面/工作区授权与查看、发送、取消、审批开关 |
| 运行与会话 | 运行元数据和状态 |
| 审批策略 | 待审批列表、远程审批与生物识别策略 |
| 审计日志 | 操作者、目标资源、结果和请求 ID |
| 系统设置 | Server、Token、通知、审计与运行环境 |

## 7. 视觉与交互规范

- 桌面管理后台采用侧边导航、指标卡、数据面板和表格。
- App 使用 390 pt 手机框架，模拟状态栏、底部导航和审批弹层。
- Connector 使用独立桌面窗口，避免与手机或管理后台混淆。
- 支持浅色/深色主题。
- 使用 inline SVG 图标，无外部图片依赖。
- 主要按钮提供 Toast 或页面状态反馈。
- `Escape` 可关闭手机审批弹层。
- 小屏幕下隐藏辅助导览并允许内容滚动。

## 8. 演示时必须说明的限制

1. 二维码是示意图形，不可扫描。
2. 配对码、指纹和 Server 均为固定演示值。
3. “连接”“授权”“吊销”“发送”不执行真实操作。
4. 切换页面只改变浏览器内存状态，刷新后恢复初始演示数据。
5. 原型不是实际 Connector，也不会随 DSH 启动。
