# DSH Connect 产品设计文档

- 文档状态：产品方案
- 版本：v1.0
- 日期：2026-10-27
- 产品形态：React Native App + Web 管理后台 + 桌面 Connector

## 1. 产品定位

一句话：

> 让用户离开电脑后仍能安全地查看、推进和审批 DSH 会话；让管理员治理谁能控制哪台桌面、访问哪些工作区、执行什么操作以及发生过什么。

### 产品原则

1. App 聚焦高频控制，不复制完整桌面 IDE。
2. 管理后台聚焦权限和治理，不成为第二个聊天客户端。
3. 桌面接入必须由用户显式确认，不默认开放整台电脑。
4. 离线不静默执行旧命令，审批异常不自动批准。
5. 所有执行状态清楚区分“已接受”“运行中”和“已完成”。

## 2. 用户与场景

| 角色 | 核心诉求 | 主要端 |
|---|---|---|
| 个人开发者 | 离开电脑后继续自己的任务 | App |
| 团队成员 | 控制被授权的桌面和工作区 | App |
| 团队管理员 | 用户、设备、权限与异常治理 | 管理后台 |
| 安全审计员 | 查看敏感操作，不参与执行 | 管理后台 |
| 系统所有者 | 初始化服务、安全基线和所有权 | 管理后台 |

### 核心用户故事

1. 用户收到任务完成通知，打开 App 查看结果并继续追问。
2. Agent 请求高风险工具，用户核对命令和工作区后允许一次或拒绝。
3. 用户发现任务方向错误，取消当前 Turn 并发送纠正指令。
4. 管理员生成桌面配对码，用户在 DSH 桌面 Connector 中确认接入。
5. 手机丢失后，用户或管理员吊销该设备，阻止后续命令。
6. 桌面离线时，用户明确看到不可发送，而不是误以为指令已执行。

## 3. 产品对象与关系

```text
Organization
├── User
│   ├── Mobile Device
│   └── Role / Group
├── Desktop Device
│   ├── Connector Identity
│   └── Workspace Grant
├── Session
├── Command / RequestId
├── Approval
└── Audit Event
```

- Desktop Device 与 Mobile Device 分开管理、分别吊销。
- Workspace Grant 是远程访问的主要资源边界。
- Session 始终属于桌面 DSH，不因远程展示而迁移所有权。

## 4. 移动 App 信息架构

```text
会话｜待办｜设备｜我的
```

### 4.1 首次启动

```text
欢迎页
→ 输入/扫码识别 Server
→ 登录或扫描个人配对码
→ 设置手机名称
→ 启用生物识别
→ 请求通知权限
→ 会话首页或无桌面空状态
```

要求：

- 配对码短时、一次性。
- 明确展示当前 Server。
- 通知权限被拒绝不阻断基本使用。
- 无桌面时提供“添加 DSH 桌面”的清晰入口，而非展示虚假在线设备。

### 4.2 会话首页

页面元素：

- 当前设备/全部设备选择器。
- 搜索。
- 全部、运行中、待处理、异常/完成筛选。
- 会话卡片。
- 新建会话按钮。

会话卡片：

- 标题、设备、工作区。
- 当前状态。
- 最后消息摘要。
- 更新时间和未读标记。

### 4.3 会话详情

顶部：

- 会话标题。
- 桌面在线状态。
- 工作区。
- 当前运行状态。
- Preset/模型摘要。

消息区：

- 用户、Assistant、工具调用和结果摘要。
- 流式回答。
- 历史分页。
- 长消息折叠、代码复制。
- 错误、取消和重连状态。

输入区：

- 多行文本。
- 默认“排队发送”。
- 高级“立即引导”（`steer`）。
- 停止当前 Turn。
- 后续版本附件入口。

发送状态：

```text
草稿 → 发送中 → DSH 已接受 → 执行中 → 已完成
                              ├→ 已取消
                              └→ 执行失败
```

### 4.4 新建会话

默认字段：桌面设备、工作区、首条提示词。

高级字段：Agent Preset、模型。

默认沿用上次设备和工作区，避免重复配置。

### 4.5 待办中心

类型：

- 待审批。
- 执行失败。
- 等待用户输入。
- 设备异常中断。

审批卡片展示风险、会话、设备、剩余有效时间和当前状态。

### 4.6 审批详情

必须展示：

- 工具名称与操作说明。
- 命令或参数摘要。
- 桌面、工作区和会话。
- 发起者与申请原因。
- 风险等级和有效期。

操作：允许一次、拒绝、查看会话。

首版不提供永久允许、同类全部允许、远程关闭审批或通知横幅直接批准高风险操作。

审批状态：

```text
pending / allowed / rejected / expired / consumed_elsewhere / cancelled
```

### 4.7 设备页

桌面卡片：

- 名称、在线状态。
- DSH/Connector 版本。
- 活跃会话数。
- 最后在线和连接质量。

提供“DSH 桌面如何接入？”说明入口，链接到桌面配对流程。

设备详情：

- 连接方式、版本、最后同步。
- 已授权工作区与动作。
- 重命名、解除配对。

解除配对不删除本地 DSH 会话，不默认取消运行任务。

### 4.8 我的

- 当前账号和 Server。
- 我的手机设备。
- 生物识别。
- 通知设置。
- 锁屏隐私。
- 设备密钥信息。
- 缓存与诊断。
- 退出登录/解除本机配对。

## 5. 桌面 Connector 产品方案

桌面 Connector 是 DSH 接入的必备产品界面，不是原型预览插件。

### 5.1 未连接页

- Server 地址。
- 一次性桌面配对码。
- 连接按钮。
- 配对码获取指引。
- 主动出站连接说明。
- Connector 能访问哪些 DSH 能力的说明。

### 5.2 待授权页

- Server 地址。
- 桌面名称。
- 设备指纹，要求与后台一致。
- 工作区多选与动作范围。
- 远程执行风险提示。
- 取消、确认授权并上线。

### 5.3 已连接页

- 在线状态和心跳。
- Server 与设备指纹。
- Connector 版本。
- 已授权工作区。
- 接入日志。
- 修改授权、断开连接、解除配对。

### 5.4 异常页

- 配对码过期或已使用。
- Server 不可信/证书异常。
- Connector 与 Server 版本不兼容。
- 用户拒绝授权。
- 网络离线和自动重连。

## 6. Web 管理后台信息架构

```text
概览
用户与角色
设备管理
访问策略
运行与会话
审批策略
审计日志
通知设置
系统设置
```

### 6.1 概览

指标：在线桌面、活跃会话、今日远程指令、待审批、失败和离线设备。

区域：高风险审批、最近失败、Connector 异常、版本不兼容、最近安全事件。

默认只展示会话元数据。

### 6.2 用户与角色

- 邀请、禁用、启用。
- 重置凭据、强制下线。
- 查看手机设备与授权范围。
- 吊销用户全部移动设备。

| 能力 | Owner | Admin | Member | Auditor |
|---|---:|---:|---:|---:|
| 系统设置 | ✓ | 部分 | — | — |
| 用户与设备管理 | ✓ | ✓ | — | — |
| 配置访问策略 | ✓ | ✓ | — | — |
| 控制授权会话 | ✓ | 按授权 | ✓ | — |
| 远程审批 | ✓ | 按授权 | 按授权 | — |
| 查看审计 | ✓ | ✓ | 本人记录 | ✓ |
| 转让 Owner | ✓ | — | — | — |

Admin 不天然拥有查看所有会话正文的权限。

### 6.3 设备管理

桌面 Connector：名称、主机、用户、在线状态、版本、工作区、活跃会话、配对与密钥轮换信息。

手机设备：所属用户、系统、App 版本、最近登录、推送状态、生物识别与风险状态。

操作：生成配对码、分配授权、禁用、吊销、轮换密钥。

### 6.4 添加桌面向导

```text
1. 生成配对码
2. 等待 Connector 建立连接
3. 桌面确认指纹和工作区授权
4. 设备上线
```

向导显示：二维码、Server、配对码、有效期、设备指纹、当前状态和前往桌面确认入口。

### 6.5 访问策略

模型：

```text
谁：用户 / 用户组
可以访问：桌面 / 工作区 / 会话
可以执行：查看 / 发送 / 取消 / 审批 / 附件
```

默认拒绝；远程审批独立授权；高风险操作可要求二次认证。

### 6.6 运行与会话

用于运维：会话元数据、当前操作者、运行状态、最近命令、失败摘要和同步状态。

允许取消异常任务、断开 Connector、打开审计。会话正文访问需独立敏感权限，首版建议不开放。

### 6.7 审批策略

- 是否允许远程审批。
- 哪些角色、工具和工作区允许。
- 高风险二次认证。
- 审批有效期与超时行为。
- 是否保留桌面审批链。

### 6.8 审计日志

字段：时间、用户、客户端设备、来源 IP、目标桌面/工作区/会话、动作、requestId、结果、失败原因、审批决定、权限差异。

支持筛选、导出和独立保留周期。

### 6.9 系统设置

Server 地址、配对码与 Token 有效期、认证策略、APNs/FCM、通知隐私、保留周期、设备数量限制、Connector 最低版本、命令超时与限流。

## 7. 通知设计

优先级：高风险审批 > 等待输入 > 执行失败 > 任务完成 > 设备状态。

要求：

- 深链到会话或审批。
- 锁屏默认只显示状态，不显示正文。
- 用户可选择详细通知。
- 手机离线恢复后，以 DSH 会话状态为准，不仅依赖推送。

## 8. 离线与冲突

| 场景 | 产品行为 |
|---|---|
| App 无网络 | 保留草稿，明确不可发送 |
| 桌面离线 | 不自动排队执行，显示离线 |
| Server 重启 | 按 requestId 去重，按游标恢复 |
| 多端同时发送 | 展示操作者，采用 queue/steer 语义 |
| 多端同时审批 | 第一个有效决定消费，其余显示已处理 |
| 手机被吊销 | 阻止新命令，不默认取消运行 Turn |
| Connector 被吊销 | 断开新控制，不删除 DSH 会话 |
| 会话正在运行 | 默认排队，立即引导需要明确选择 |

## 9. 非功能要求

- 虚拟化长会话列表，避免大量 DOM。
- 支持动态字体、读屏和足够对比度。
- 中英文界面文案可本地化。
- 支持明暗主题。
- 高风险操作二次确认。
- 权限变更和设备吊销即时生效。
- 所有敏感操作可审计。
- 管理后台默认仅显示会话元数据。

## 10. 产品指标

### 北极星指标

每周通过 App 成功推进的会话数：完成至少一次“远程指令 → DSH 执行 → 结果返回”闭环。

### 激活

- 桌面配对成功率。
- 手机配对成功率。
- 配对后 24 小时内完成首次远程控制的比例。

### 体验

- 命令接受成功率。
- 流式事件延迟。
- 断线恢复成功率。
- 重复命令率。
- 通知打开率。
- 审批响应时间。

### 安全约束

- 吊销后成功执行的新命令数必须为 0。
- 审批超时后误执行数必须为 0。
- 未授权工作区访问成功数必须为 0。
